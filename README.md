# Barbearia Feitoza

Site estático institucional pronto para Vercel. Publique a pasta como projeto estático, sem comando de build.

## Arquivos

- `index.html`: estrutura e SEO básico.
- `style.css`: layout responsivo e identidade visual.
- `script.js`: menu móvel, links de WhatsApp e animações discretas.

## Dados a confirmar antes da publicação final

- Permanência da nota 5,0 e das 7 avaliações do Google Maps.
- Disponibilidade dos serviços e horário de atendimento.
- Perfil oficial do Instagram, caso seja desejado no site.
